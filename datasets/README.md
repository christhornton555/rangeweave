# Datasets

Do not commit arbitrary raw personal captures here.

This directory is for **small, intentionally published, documented** fixtures such as:

- protocol golden recordings;
- stationary calibration snippets;
- simple flat-wall/known-motion validation captures;
- regression datasets whose publication is deliberate.

Large/local captures should live outside the repository and are ignored by the default `.gitignore` pattern for `captures/` / `capture_*` directories.

Every published dataset should state hardware revision, firmware/protocol/calibration versions, coordinate conventions and capture purpose.
