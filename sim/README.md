# Simulation

**Status: PLANNED.**

Simulation will become useful once the conventional geometry/estimation pipeline exposes measurable failure modes. Planned domain randomization includes IMU bias/noise/timing/temperature, ToF bias/dropouts/multipath/reflectance/ambient IR/crosstalk, scene geometry/dynamics and trajectories.

Learned components should be evaluated against conventional baselines and should output bounded corrections/confidence/uncertainty rather than unquestioned absolute pose.
